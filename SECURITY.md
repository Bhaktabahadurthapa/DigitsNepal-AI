# Security Policy

Please report vulnerabilities privately. Do not open a public issue for security problems.

- Email: the address configured as `NEXT_PUBLIC_CONTACT_EMAIL` for the deployment (to be published before launch).
- Include steps to reproduce, the affected URL/endpoint, and the impact.
- Do not access, modify or delete other users' data, and do not run denial-of-service or social-engineering tests.

We aim to acknowledge reports within 5 working days. See `docs/security.md` for the current control checklist.
